About Decision Viewer

Who made it

Created by Danilo Jončić.

How to use it

Search by incident, boat, event, or rule. Narrow the results by event, hearing type, year, or rules, then select a decision to read its facts, conclusions, and outcome. Search tips show examples of more specific searches.

How it stays up to date

Cases are stored as JSON files in the GitHub repository. Each successful publication rebuilds the viewer from those files. The date beside the title shows when this version was built, in UTC. Refresh the page after a new version is published to see the latest cases.
